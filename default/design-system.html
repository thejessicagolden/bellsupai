Bells Up AI design system

Web + Product Design System

Use this page as the primary system architecture and implementation guide for Bells Up AI front-end development across marketing, product, AI workflows, dashboards, documentation, webinar systems, email, and internal operations. Includes semantic tokens, color system, typography scale, spacing, components, and accessibility guidance.

System priorities

This design system is built to communicate credibility, precision, trust, clarity, and long-term institutional maturity. It is intentionally calm, structured, typography-led, restrained, and accessible while supporting scalable theming, enterprise extensibility, and consistent implementation across all Bells Up AI experiences.

Design themes

  • Operational reliabilityStable surfaces, clear hierarchy, trusted form
  • Technical precisionMeasured type, structured grids, restrained contrast
  • Editorial sophisticationReadable copy, deliberate spacing, institutional tone
  • Low cognitive loadStrong rhythm, simplified states, predictable navigation

Scalable system scope

  • Marketing websiteBrand-facing pages, hero messaging, product positioning
  • Product UIWorkflow panels, forms, dashboards, path-based UI
  • AI workflowsPrompt modules, response states, citation panels
  • DocumentationGuides, templates, legal and white paper systems
  • Email + socialAnnouncements, narrative templates, publication layouts
Design tokens

The system is token-based and uses semantic naming for colors, typography, spacing, borders, shadows, motion, z-index, opacity, and breakpoints. Light and dark themes share the same structure with mapped values for consistent extensibility.

Core token categories

  • Color--color-*
  • Typography--text-*, --font-*
  • Spacing--space-*
  • Radius--radius-*
  • Border--border-*
  • Shadow--color-shadow
  • Motion--motion-*
  • Z-index--z-*

    Motion design

    Use restrained motion to support content flow and clarity. The page uses a subtle fade-and-rise reveal pattern for on-scroll entrance, which keeps motion calm and purposeful.

     .reveal {
  opacity: 0;
  transform: translateY(20px);
  transition: opacity 0.7s var(--motion-ease), transform 0.7s var(--motion-ease);
}

.reveal.is-visible {
  opacity: 1;
  transform: translateY(0);
}

    This is paired with an IntersectionObserver script that adds is-visible when each container enters view.

    Design guidance: Avoid startup clichés, sci-fi AI visuals, neon palettes, decorative gradients, excessive motion, glowing circuitry, and generic AI imagery. Focus on precision, calmness, and institutional clarity.
